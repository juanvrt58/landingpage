Al buscar catering para un cumpleaños, muchas veces el problema no es solo el menú: también hay que comprar, cocinar, servir y ordenar. Roble Pizzas concentra esa operación en un servicio de pizza napolitana preparado en el lugar.

La masa de fermentación lenta, los ingredientes seleccionados y el horno a alta temperatura entregan una comida recién hecha, mientras el equipo se encarga de la atención.

Preguntas frecuentes

Antes de contratar catering

¿Es solo para cumpleaños adultos? No; el formato puede adaptarse a celebraciones familiares y distintos tipos de invitados.

¿Qué debe tener el lugar? Un espacio adecuado para instalar el horno y acceso para el montaje; los detalles se revisan antes de confirmar.

¿Cómo se calcula? El cotizador usa la cantidad de invitados y la tabla de referencia del servicio.
